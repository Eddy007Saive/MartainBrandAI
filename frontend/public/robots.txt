# Postorico — robots.txt

# Les robots d'IA sont accueillis explicitement : quand quelqu'un demande a
# ChatGPT, Claude ou Perplexity « quel outil pour gerer mes reseaux ? », on ne
# peut etre cite que si on a ete lu.
#
# Deux familles a ne pas confondre :
#   - les robots d'INDEXATION (recherche, citation en direct) : on veut leur
#     visite, ils nous rendent visibles ;
#   - les robots d'ENTRAINEMENT : ils lisent pour nourrir un modele, sans
#     renvoyer personne. GPTBot fait les deux, on l'accepte quand meme : le
#     refuser coute une citation dans ChatGPT.
#
# Ce fichier n'a de valeur que si les pages contiennent vraiment du texte.
